TORYAK WR — نسخة جاهزة للنشر (مكتبة نماذج عامة)

محتويات الحزمة:
- index.html: الصفحة الرئيسية ومحرر النماذج.
- models/: ملفات GLB/GLTF وخامات النماذج العامة. لا تحذف المجلد أو تفصله عن index.html.

النشر الأسهل باستخدام Netlify Drop:
1) فك ضغط ملف ZIP إلى مجلد على جهازك.
2) افتح https://app.netlify.com/drop في المتصفح.
3) اسحب المجلد الذي يحتوي على index.html ومجلد models إلى منطقة الرفع، أو اختر المجلد.
4) بعد انتهاء الرفع، افتح رابط الموقع الذي ينتهي بـ netlify.app واحتفظ به.

إذا لم يقبل Netlify الرفع:
- احتفظ بالمجلد نفسه، واستخدم GitHub Desktop لرفعه إلى مستودع جديد. ثم في GitHub افتح Settings > Pages، واختر Deploy from a branch، والفرع main والمجلد /(root). المرجع الرسمي: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

ملاحظات:
- لا ترفع index.html وحده. يجب رفع مجلد models معه.
- الموقع يحتاج اتصالًا بالإنترنت لتحميل مكتبات Three.js من CDN.
- زر «نشر المشروع» في التطبيق الحالي يخزن بيانات المشروع داخل متصفح المستخدم؛ لكي تظهر المشاريع لجميع الزوار تحتاج قاعدة بيانات/خادمًا.
- هذه النسخة تستبعد نماذج المسدس والبندقية المدمجة وتحتفظ بالنماذج العامة مثل الولاعة ولوحة الدوائر والجالون وبوني والحوت والبطة واليوكليلي والساعة وغيرها.

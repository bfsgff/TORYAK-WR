TORYAK WR — ملفات جاهزة للرفع إلى GitHub Pages

المجلد يحتوي على:
- index.html: الصفحة الرئيسية.
- models/: ملفات المجسمات والخامات المطلوبة للمعاينات.
- .nojekyll: ملف فارغ مفيد للنشر الثابت عبر GitHub Pages.

طريقة الرفع دون إضافة الملفات واحدًا واحدًا:
1. فك ضغط هذا الملف على جهازك.
2. افتح GitHub Desktop وثبّته إن لم يكن موجودًا: https://desktop.github.com/
3. إذا كان لديك مستودع GitHub جاهز: في GitHub Desktop اختر File > Clone Repository ثم اختر مستودعك واحفظه على الكمبيوتر.
4. انسخ محتويات هذا المجلد (index.html وmodels ومجلدات الملفات الأخرى وملفات README) إلى المجلد المحلي للمستودع الذي استنسخته. وافق على الاستبدال إذا ظهرت رسالة.
5. ارجع إلى GitHub Desktop؛ ستظهر الملفات الجديدة/المعدّلة. اكتب ملخصًا مثل: Add TORYAK WR site files
6. اضغط Commit to main (أو الفرع الحالي)، ثم Push origin.
7. في صفحة المستودع على GitHub، افتح Settings > Pages، واختر Deploy from a branch، وحدد الفرع main والمجلد /(root)، ثم احفظ.
8. بعد اكتمال النشر سيظهر رابط الموقع في صفحة Pages.

مهم:
- لا ترفع ملف ZIP نفسه إلى جذر الموقع وتتوقع أن يُفك ضغطه تلقائيًا؛ يجب فك الضغط محليًا أولًا.
- أبقِ مجلد models بجوار index.html ولا تغيّر أسماء مجلداته، لأن الصفحة تستخدم مساراتها.
- إذا كانت الملفات موجودة أصلًا في المستودع، انسخ فوقها فقط إذا كنت تريد استبدال النسخة القديمة.
- بعض الميزات التي تحفظ المشاريع محليًا لا تزامنها تلقائيًا بين الزوار؛ هذا يحتاج خادمًا وقاعدة بيانات.
